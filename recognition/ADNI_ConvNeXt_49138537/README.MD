##  AD vs NC MRI Classification with ConvNeXt (PyTorch)

###  Problem  
Classify whether an MRI brain image belongs to **Alzheimer’s Disease (AD)** or **Normal Control (NC)** using a deep convolutional neural network.

###  Algorithm  
A **ConvNeXt-based CNN** is trained on labelled MRI slice images to learn discriminative structural patterns between AD and NC brains.

###  How It Works  
- **Data preparation:**  
  The dataset is organised into multiple folders:  
- Each image is converted into a tensor of shape **(Batch, Channel, Height, Width)**.  
- Input size: **224×224**, 3 channels (converted from grayscale).  

### Model Architecture  
ConvNeXt follows a hierarchical design with **four stages** containing `[3, 3, 9, 3]` ConvNeXt blocks.  
Each block includes:
- Depthwise convolution (7×7 kernel)  
- LayerNorm (channels_last)  
- Two pointwise (1×1) convolutions with GELU activation  
- Optional layer scaling and stochastic depth (DropPath)  

The final **linear head** outputs logits for **two classes**: AD and NC.

### Training  
- **Loss:** Cross-Entropy  
- **Optimizer:** Adam / AdamW  
- **Scheduler:** Optional cosine or step LR  
- **Checkpoints:** Saves `best.pt`, `last.pt`, and logs training metrics  
- **Metrics:** Accuracy and loss curves plotted per epoch
